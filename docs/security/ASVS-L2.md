# سیاههٔ OWASP ASVS سطح ۲ — سامانهٔ زائرسرای مهدیه

> این سند **شاهد-محور** است: هر مورد یا به فایل/آزمون/فرمان مشخص اشاره می‌کند،
> یا صریحاً «دستی» و «باقی‌مانده» علامت خورده است. موردی که شاهد ندارد،
> انجام‌شده حساب نمی‌شود — این تصمیم، تفاوت «سند امنیتی» و «تشریفات» است.

**دامنه:** مسیر زائر (وب + API) و مسیر کارکنان. **نسخهٔ ASVS:** ۴.۰.۳ سطح ۲.
**آخرین به‌روزرسانی:** ۱۴۰۵/۰۷/۲۴ (۲۰۲۶-۱۰-۱۶) — همراه با فعال‌سازی پنل پیامک واقعی.

## تأیید تکرارپذیر

```bash
make verify                     # ruff + mypy + pytest + coverage
make security                   # bandit + pip-audit --strict
make django-check               # check --deploy (تولید) + drift مهاجرت
bash scripts/deploy_smoke.sh    # TLS/هدرها/دارایی‌ها/SIGTERM
make audit-verify               # یکپارچگی زنجیرهٔ حسابرسی و لنگرها
```

> هر ادعای ✅ در این سند باید با یکی از پنج فرمان بالا قابل بازتولید باشد. اگر
> روزی نشد، سند کهنه است — و کهنه‌بودن سند امنیتی، خودش یک یافتهٔ امنیتی است.
